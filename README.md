# BOTW Web Save Editor

A static, browser-based save editor for The Legend of Zelda: Breath of the Wild, based on [Xunzi229/Botw-Savediter](https://github.com/Xunzi229/Botw-Savediter).

This repository contains a conversion script and GitHub Pages workflow. Save files are processed locally and not uploaded.
